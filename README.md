# Unslip releases

Every released `Unslip.exe` for Windows, one GitHub release per version, at a link that never changes.

Unslip is free autocorrect for Windows 10 and 11: it fixes typos as you type, judged by the keys around each
slip on the keyboard you use. Website, in-browser demo and privacy policy: https://unslip.grounders.app

This repository holds only the released files; the source code isn't published.
Questions: support@grounders.app
